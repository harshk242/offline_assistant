Ingest extracts each PDF page with pdfplumber, tables included, and stores it in a SQLite FTS5 table with manual, page and nearest heading. Each page gets a stable ID (file hash plus page number) so phase 2 can add embeddings without re-parsing. At query time we run BM25 over the question, take the top 3 pages, and make a single capped LFM3 call that must answer from those pages and cite them. If nothing clears the score threshold we say "not found" and skip the model entirely.

All numbers are from our benchmark script on the board. The bars show total response time split into prefill (orange) and generation (blue). Going from 570 to 3,450 prompt tokens only adds about 2.6 seconds, because prefill runs around 1,200 tokens per second. Generation at about 41 tokens per second dominates, which is why we cap answers at 200 tokens. Our real prompt is three pages, around 2,000 tokens, so expect roughly 6 to 7 seconds for a capped answer. Over 20 back-to-back queries the speed didn't drop and the NPU stayed under 69 °C. The model server uses under 400 MB of RAM.

Every expected answer was checked by hand against the PDF, with both the PDF page and the printed page recorded, since they differ in two of the three manuals. Paraphrase questions are the largest group on purpose: they're where keyword search is expected to struggle and where phase 2 has to prove itself. Images and voice come after that, and voice sets up the bigger idea on the next slide.

Field fixes feed back

The next technician’s assistant knows what worked

This is where it goes beyond answering questions. The same voice pipeline from V3 lets a technician log their work hands-free. Example: "Replaced the shaft seal on pump 3, checked rotation, no leaks." The model turns that into a structured record: equipment, fault, action taken, parts used, and the manual page it relates to. Records queue on the device while offline and upload when it reconnects. On the server they become service history and fleet-wide fault trends, and the fixes that worked flow back into the assistant on every device.
